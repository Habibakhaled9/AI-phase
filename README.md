# AI Phase — Course Work Documentation

This repository documents the work completed during the course sessions and the related home assignments.

## Branches

- `session1`: work completed during Session 1.
- `session1-assignment`: the Session 1 home assignment.

## Setup

1. Clone the repository.
2. Switch to the branch you want to review.
3. Copy `.env.example` to `.env` and fill in any required local values.
4. Follow the branch-specific notes in this README.

> Do not commit `.env` or any real secrets.
